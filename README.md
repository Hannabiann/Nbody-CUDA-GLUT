# Nbody-CUDA-GLUT

An old N-body simulator using the FreeGLUT graphics library; an updated and faster version exists that uses the Vulkan graphics library [Nbody-CUDA-Vulkan](https://github.com/Hannabiann/Nbody-CUDA-Vulkan/).
